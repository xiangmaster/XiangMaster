## ✦ Featured Research

### 🔧 01 · Automated Vulnerability Repair

<img src="https://img.shields.io/badge/PRIMARY_RESEARCH_FOCUS-FF4D6D?style=for-the-badge">

> [!IMPORTANT]
> **LLM-based Automated Vulnerability Repair**
>
> My primary research focuses on leveraging **large language models to repair software vulnerabilities**, especially complex vulnerabilities that require richer contextual information, multi-step reasoning, and coordinated modifications across multiple program locations.

#### What I'm exploring

🧩 **Multi-hunk Vulnerability Repair**  
Repairing complex vulnerabilities whose patches span multiple code locations.

🧠 **Context Selection & Organization**  
Identifying useful program context and presenting it effectively to large language models.

🔄 **Repair Workflow Design**  
Designing structured multi-step workflows for complex vulnerability repair.

🔍 **Program Analysis + LLMs**  
Combining static/program analysis signals with the reasoning capabilities of foundation models.

✅ **Reliable Security Patching**  
Improving the correctness and reliability of automatically generated vulnerability patches.
